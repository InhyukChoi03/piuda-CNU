# ESP32 통합 생활 신호 센서

한 ESP32가 Raspberry Pi의 `PIUDA-CNU` 핫스팟에 고정 연결해 다음 값을 1초마다 전송합니다.

- PIR 움직임 상태(GPIO 14)
- Wi-Fi CSI 요약값(라즈베리파이 AP 응답 프레임)
- MLX90614 주변·비접촉 표면 온도(I²C GPIO 21/22, `room_1`만)

별도 CSI 송신기는 필요하지 않습니다. Raspberry Pi 핫스팟이 채널 6에서 고정된 CSI 기준 신호를 만들고, ESP32가 게이트웨이에 초당 약 2회 ping을 보내 수신 프레임을 확보합니다.

## 두 기기 프로필

```bash
# room_1: PIR + CSI + MLX90614
deploy/flash-esp32.sh room_1 /dev/cu.usbserial-110

# room_2: PIR + CSI, 온도 센서 없음
deploy/flash-esp32.sh room_2 /dev/cu.usbserial-110
```

두 프로필 모두 기본 보드 `esp32:esp32:esp32`, Arduino-ESP32 3.3.11을 사용합니다. 첫 30초 동안 CSI 기준선을 교정하므로 보드·Pi·전원선을 움직이지 말고 사람도 측정 경로를 비워 두세요.

## 고정 네트워크

- SSID: `PIUDA-CNU`
- 비밀번호: `piuda3017`
- 서버: `http://192.168.4.1:8080/api/v1/module-readings`
- 센서 키: 발표용 `piuda-demo-3017`

이 값은 인터넷 공개 운영용 자격증명이 아니라 시연 장비를 즉시 연결하기 위한 고정값입니다. 실제 운영에서는 핫스팟 비밀번호와 센서 키를 별도로 바꾸고 펌웨어도 다시 빌드해야 합니다.

## 판정 범위

서버는 초당 측정값 전체를 계속 쌓지 않고 기기별 최신 상태만 갱신합니다. PIR 전환, CSI 움직임, 1분 상태 신호처럼 의미 있는 변화만 이벤트로 남깁니다. CSI는 30개 정지 표본으로 기준선과 편차를 잡은 후 움직임을 분류합니다. 큰 CSI 변화와 PIR 움직임이 동시에 있을 때만 `낙상 의심` 후보를 만들며, 이는 학습 모델이나 의료기기 판정이 아니라 보호자 확인을 유도하는 보조 신호입니다.

MLX90614의 `object` 값은 측정 대상의 비접촉 표면 온도입니다. 화면에서 체온이나 발열 진단값으로 표시하지 않습니다.
