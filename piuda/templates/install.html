PIN으로 로그인해 건강 점수·일정·센서를 확인하고 사용자와 통화합니다.

https://CNU.local:8443/caregiver

최초 1회만

보호자 음성 통화 준비

1. 인증서 받기피우다 통화 인증서를 받습니다.
2. 프로파일 설치설정 → 일반 → VPN 및 기기 관리에서 설치합니다.
3. 인증서 신뢰설정 → 일반 → 정보 → 인증서 신뢰 설정에서 Piuda를 켭니다.
4. 보안 주소 열기보호자 통화 화면에서 마이크를 허용합니다.

아이폰 설치 방법

같은 Wi-Fi 연결아이폰과 Raspberry Pi를 동일한 공유기에 연결합니다.
Safari로 열기QR을 스캔한 뒤 Safari에서 페이지를 엽니다.
⋯ 또는 공유 선택최신 Safari는 아래쪽 ‘⋯’에서 공유를 누릅니다. 이전 버전은 사각형·위쪽 화살표 버튼을 누릅니다.
홈 화면에 추가‘홈 화면에 추가’와 ‘웹 앱으로 열기’를 선택하고 추가합니다.

CNU.local이 열리지 않으면 Pi가 현재 받은 IP 주소의 http://IP주소:8080/install을 여세요. 이 페이지가 보호자 통화 주소도 같은 IP로 자동 맞춥니다.
